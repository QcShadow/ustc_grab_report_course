这是怎么工作的

1填写邮箱与平台 Cookie，保存配置。
2用“报告预览”确认筛选条件和院系优先级。
3安装定时任务，服务会按间隔自动检测并抢课。
4抢到课程或 cookie 过期时会发邮件通知。

怎么获取 Cookie？
  1. Chrome 登录 https://yjs1.ustc.edu.cn
  2. F12 → Network → 点任意 gsapp 请求 → Headers
  3. 复制 Request Headers 里 Cookie: 后面的整段
  4. 按分号拆成上面的四个字段

客户端会按应用自动刷新并缓存 _WEU，填任意页面的值即可。
